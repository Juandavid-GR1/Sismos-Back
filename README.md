# Backend - Sistema de Observación Sísmica

## Requerimientos Previos
- Python 3.x
- pip

## Dependencias Necesarias
- Flask
- flask-cors

## Guía de Inicio Rápido
1. Clonar el repositorio y navegar a la carpeta 'backend'.

2. Crear y activar un entorno virtual.

python -m venv venv 

- Comandos específicos para Windows y macOS/Linux.

venv\Scripts\activate Windows

source venv/bin/activate Mac/Linux


3. Instalar dependencias usando 'pip install -r requirements.txt'.

## Ejecutar el Servidor
`python app.py`
